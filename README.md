# wells

<img src="https://cdn.hackclub.com/01a0b1f5-4c50-7989-81f6-a9f8f11c2edf/wells.png" width="800" alt="wells, seed 6">

a shader for [wpr](https://github.com/maxwofford/wpr), the wallpaper manager.

```sh
brew tap maxwofford/wpr && brew install wpr   # if you don't have wpr yet
wpr install maxwofford/wells                  # (it's one of the defaults, so you may already have it)
wpr gen wells                                 # a new one, set as your wallpaper
wpr enable wells                              # add it to your rotation
```
